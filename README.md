# Autovisor 3.18.4（修改版）

基于开源项目 **CXRunfree/Autovisor 3.18.4** 修改。

- 原项目地址：https://github.com/CXRunfree/Autovisor

## 二、为什么要改

1. **学完会静默复习**：某门课程的待学课时为 0 时，原版会自动进入“复习模式”，把已完成的课时全部重播一遍，控制台没有任何提示，使用者不知道发生了什么。
2. **按章节行学习，会漏课**：原版以目录里的章节标题行为学习单位。
   - 单元下直接挂着课时（没有小分节）：能正常逐个播放；
   - 单元下还有一层小分节（`1.1` 下再分 `1.1.1`、`1.1.2`…，每个小分节里有多个课时）：只播放每个小分节的**第一节**课，其余课时被跳过；
   - 融合课的章节容器和课时行共用同一个 class，会出现课时重复、序号错位、点击落在容器上、进度读不到而误报“未确认播放完成”。

## 三、修改内容

1. **不再自动复习，全部完成才询问**
   每门课程学完就接着下一门；一轮结束后，只有全部课程都已完成时才询问：
   ```
   所有课程均已学完, 是否复习(重新播放已完成的课时)? [y/N]:
   ```
   - `y` / `yes` / `是`：重播已完成的课时；
   - 直接回车或其它内容：退出，本次不播放。

   只要还有课程没学完，就不询问、不复习。

2. **新增完成记录**
   每门课程的结果写入 `data\course_state.json`（只记录课程链接、课程名、状态、时间，可在程序外查看）。记录不用于跳过课程，每次启动仍会打开目录核对：原本已完成、现在又出现新课时，会自动改回未完成并继续学；一直没学完的保持原样。

3. **每轮结束打印汇总**
   汇总只有两种状态：
   ```
   [INFO] 课程 1/3: 高等数学 -> 已完成
   [INFO] 课程 2/3: 大学英语 -> 已完成
   [INFO] 课程 3/3: 线性代数 -> 未完成
   ```

4. **按具体课时选中**
   目录里每个课时节点都单独选中播放，小分节里第一节以外的课不会再漏掉，也不会重复计数。

5. **异常保护**
   课程页异常、目录中识别不到课时时，按“未学完”处理，避免误判为已学完而去弹复习询问。

6. **启动横幅**
   显示 `modified by sylvia9001`，标明这是修改版。

## 四、程序功能（沿用原版）

- 自动登录，自动通过登录滑块验证（可选）
- 自动播放、自动切换下一集
- 自动跳过弹窗和弹题
- 自动静音，可设置倍速
- 自动检测暂停并续播
- 视频播完但平台进度不足 100% 时，自动回退到对应进度点重播（最多自动重试 2 次）
- 支持智慧共享课、翻转课、融合共享课
- 支持刷习惯分
- 支持隐藏窗口后台运行
- 学时统计、实时进度、各种自定义配置

## 五、运行方式

1. 系统要求 Windows 10 及以上。
2. 用文本编辑器打开 `config.ini`，填写账号、密码和课程链接（也可以留空，启动后手动登录并手动进入课程）。
3. 双击 `Autovisor.exe` 运行。
4. 首次运行需要登录，登录状态保存在 `data\cookies.json`，**这个文件等同于免密登录凭证，不要发给别人**。

### 目录说明

| 文件 / 目录 | 说明 |
| --- | --- |
| `Autovisor.exe` | 主程序 |
| `internal\` | 程序运行所需的 Python 运行时和依赖，不可删除 |
| `packages\` | OpenCV / NumPy 等可选组件 |
| `resources\` | 图标、脚本等资源 |
| `config.ini` | 配置文件（账号、课程链接、播放参数） |
| `data\` | 运行数据：`cookies.json`（登录凭证）、`course_state.json`（完成记录）、`mirrors.json`，**分享前请删掉 `data\cookies.json` 和 `data\course_state.json`** |
| `logs\` | 运行日志，程序启动后自动创建，分享前请清空 |
